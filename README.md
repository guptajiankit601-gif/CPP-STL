## 💻 How to Run the Code

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/CPP-STL.git
   ```

2. Navigate to the project folder:

   ```bash
   cd CPP-STL
   ```

3. Compile and run any C++ program:

   ```bash
   g++ filename.cpp -o output
   ./output
   ```

   On Windows, run:

   ```bash
   output.exe
   ```
